BBL Ability Lock

# 1.4.3
- More tasks added
- Added abilitylock ability check name command 
- Removed folder names (ability/breaking -> breaking) causing too much confusion
- Ability Screen now shows abilities that cannot be unlocked during the run 
- The width and height of the task screen now more customizable on world creation
- Abilities where possible now only have a single parent. More tasks now have multiple parents, this frees up the abilities a bit more for further customization in the future

# 1.4.2
- Ported tasks to json data driven (WIP)
- Tasks now have parents, meaning that you can have a task require 1 or more other tasks to be completed before its completeable
- Tasks now have ability requirements, meaning tasks can be locked behing a specific ability eg minecraft stone requiring mining stone ability 
- Both of these changes are to help with the ability lock logic system to hopefully make it so all generated tasks cna be completed during a run

# 1.4.1
- Added crafting ability 
- Ability checker now uses Identifies not strings 
- Ability jsons now save inside a folder sub folder per ability eg ability/breaking for breaking abilities 
- Added movent ability, these are somewhat hard coded and you cant really add additional ones but most movement is included here 
- Added screen open ability, only support inventory
- Presets now data driven, must add your preset to the config so it can be loaded from selection screen on world creation
- Presets contain the name, all abilities that can be unlocked, starting abilities and one life or not
- Added standard and hardcore presets
- Removed ability lock tab from new world creation, ability lock settings are now in the "game" tab, now shows preset settings inside
